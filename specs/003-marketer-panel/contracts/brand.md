## 2. Шрифты

Встроены подмножества Exo2-Regular/Black, Inter18pt-Regular/Black, Inter24pt-Black.
Это подтверждает семейства, но не делает подмножество полноценным webfont.
«18pt» в названии Inter не требует CSS font-size:18pt для всего интерфейса.
Для выбранного полного файла проверить метаданные и, при наличии соответствующей
оптической оси/варианта, использовать подходящий Inter 18pt. Не выдумывать семейство
«Inter18ptB». Размеры, веса и межстрочные интервалы — адаптация из [ui.md](ui.md).

Планируются полные локальные шрифты с кириллицей, font-display:swap и fallback.
Официальные источники: [Exo 2 / Google Fonts](https://github.com/google/fonts/tree/main/ofl/exo2),
[Inter / автор](https://rsms.me/inter/). Для каждого файла сохранить лицензию OFL,
происхождение и checksum. Никакого runtime CDN и извлечения неполных PDF subsets.

## 3. Материалы при реализации

Планируемые файлы: `frontend/public/brand/aeza-logo-black.svg`, `aeza-logo-white.svg`,
`aeza-mark-black.svg`, `aeza-mark-white.svg`, `pattern.svg`, `asset-manifest.json`;
`frontend/public/favicon.svg`. Black/white обозначают оригинальный вариант контейнера,
а не разрешение произвольно перекрашивать логотип.
Шрифты: `frontend/public/fonts/Exo2Variable.woff2`, `InterVariable.woff2`,
`Exo2-OFL.txt`, `Inter-OFL.txt`. Полный официальный альтернативный формат допустим,
если WOFF2 нельзя получить без лишней зависимости; решение записать в manifest.

Manifest различает оригинальные материалы, наши UI-иконки и служебные цвета;
содержит источник/страницу, вариант, checksum и лицензию шрифта.
Использовать утверждённый SVG либо точно экспортированный вектор из PDF с проверкой
paths, пропорций, crop/viewBox. Скриншот страницы, Unicode é, набранные буквы,
AI-изображение и заново нарисованный похожий знак логотипом не считаются.
Если точный экспорт невозможен, конкретный материал отмечается как блокирующий;
поддельная замена не создаётся. Это требование качества, а не новый общий этап согласования.

Название продукта размещается отдельно с сохранением охранного поля. Минимальный
компактный блок: знак 24 px + по 30 px сверху/снизу = min-height 84 px; высота растёт
при необходимости. На 360 px и при 200% текста перестраивать компоновку, не ужимать поле.
Название ссылки на главную доступно; повторный декоративный знак — aria-hidden.
Тень и счётчик из макета иконки не копируются как обязательная часть favicon.

## 4. Доступность и служебные решения

Расчёт контраста непрозрачных цветов: чёрный/голубой ≈10.655:1,
тёмно-синий/голубой ≈7.067:1, белый/голубой ≈1.971:1;
чёрный/оранжевый ≈7.399:1, белый/оранжевый ≈2.838:1.
Поэтому голубая основная кнопка имеет тёмный текст; фокус и важные границы контрастные.
Голубая значимая иконка на белом требует контрастного контейнера либо монохромного
варианта. Цветная диаграмма имеет подписи и контрастные разделители/границы.
Обводка диаграммы не означает разрешение обводить логотип.

Белые поверхности, производные оттенки, красный/зелёный статусы, размеры, радиусы
и тени карточек — наши UI-решения, не дополнительные официальные цвета бренда.
Они не применяются к логотипу. Уровни риска различаются текстом, не только цветом.
Паттерн и мерч не добавляют продуктовых функций. Точные UI-пары — [ui.md](ui.md).

## 5. Приёмка

На шести экранах проверить подлинные варианты знака, пропорции, поле 30 CSS px.
У favicon проверить исходные пропорции компактного знака без требования фиксированного CSS-поля. Проверить отсутствие эффектов, фактическую загрузку Exo 2/Inter и кириллицы,
роль основного голубого, HEX, заливные иконки с названиями.
Нужны снимки 1440/360 px и контроль 200% текста, ошибок, загрузки и фокуса;
контраст измеряется на реальных стилях. Проверить локальную загрузку и отказ шрифтов.
Отсутствующий материал и непроведённая ручная проверка явно отмечаются.
Одной декларации font-family в CSS недостаточно для подтверждения загрузки шрифта.
