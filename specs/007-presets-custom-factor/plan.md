# Implementation Plan: пресеты и седьмой признак

**Branch**: `main` | **Date**: 2026-10-24 | **Spec**: [spec.md](spec.md)

## Summary

Добавить таблицу `weight_presets` и эндпоинты `/model/presets` (список, создание,
удаление), блок «Наборы весов» в настройках и седьмой признак `auto_off_share`
с объявлением поколения 2. Пресеты меняют только веса; новый признак по умолчанию
с весом 0, поэтому прежние оценки остаются прежними.

## Technical Context

**Backend**: Python 3.12, FastAPI, SQLite; `FEATURE_GENERATIONS` уже поддерживает
аддитивные поколения, `upgrade_settings` добавляет новые коды с весом 0.
**Frontend**: React, существующий `SettingsDraft` (черновик + save), новые кнопки и диалоги.
**Testing**: pytest (`test_presets.py`, `test_settings_upgrade.py`), e2e Playwright.

## Constitution Check

| Принцип | Как соблюдён |
|---|---|
| I | Тот же стек и механизм поколений, без новых зависимостей |
| II | Пресеты — продуктовое решение команды, не требование кейса |
| III | Только веса; пороги и деньги не тронуты |
| IV | Новые пути аддитивны, контракты settings не меняются |
| V | Ошибки валидации возвращают 409/422, настройки не портятся |
| VI | Новый признак объяснён в интерфейсе и документации |
| VII | Вес 0 = признак не влияет; старые данные читаются |
| VIII | Честно: новый признак эвристический, не «улучшение точности» |
| IX | 8 новых тестов пресетов + обновлённые тесты поколений |
| X | Спека/план/задачи Spec Kit, коммит в main по просьбе команды |

## Structure

```text
backend/app/presets.py          # встроенные наборы, валидация, CRUD
backend/app/db.py               # таблица weight_presets
backend/app/api.py              # /model/presets
backend/app/scoring.py          # auto_off_share + поколение 2
frontend/src/pages/Settings.tsx # блок «Наборы весов», диалоги
frontend/src/styles.css         # карточки пресетов, отступ заголовка
```

## Risks

- Изменение generations затрагивает тесты расширяемости — они обновлены на
  динамическое «следующее поколение».
- Пресет применяется в черновик, чтобы сохранить защиту несохранённых правок.
