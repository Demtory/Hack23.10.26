# Питч-дека (3-минутная защита)

`risk-desk-pitch.pptx` — 7 слайдов, 16:9 widescreen, собирается скриптом `build_pitch.py`.
Каждый слайд снабжён готовыми **заметками для докладчика** (хронометраж, точные слова и акценты) — откройте режим докладчика в PowerPoint.

Хронометраж рассчитан на **спокойный / медленный темп речи** (80 слов/мин):
всего **229 слов** (~2:45 с безопасным запасом 15 секунд на паузы и переключения).

## Структура 7 слайдов

1. **Титул:** *«Кому звонить сегодня, почему и что сказать»* (18 сек) — позиционирование как инструмента маркетолога.
2. **Специфика хостинга:** *«Удалённый сервер вернуть нельзя»* (32 сек) — 67,53 € под риском, отток перехватывается на `suspended` и `prolong_wait`.
3. **Решение: Дашборд:** *«Три ответа ТЗ — один рабочий экран»* (25 сек) — крупный скриншот основного интерфейса маркетолога.
4. **Действие: Retention:** *«От анализа к действию: удержание в 1 клик»* (25 сек) — крупное окно персонального письма с автоподстановкой.
5. **Методология и честность:** *«Прозрачные правила вместо чёрного ящика»* (30 сек) — почему не ML на 10 строках, 7 признаков с весами в UI, формула реальных денег.
6. **Инженерия и прод:** *«Готов к бою: одна команда запуска и 449 тестов»* (25 сек) — `docker compose up`, 449 тестов, 10 e2e, 10k клиентов за 3.1 с, Swagger, Prometheus, SSO.
7. **Итог и Q&A:** *«ОТТОК · Risk Desk»* (15 сек) — готовность к вопросам, прямой QR-код без редиректов на `docs/JURY.md`.

## Пересобрать

```bash
pip install python-pptx qrcode pillow
python pitch/build_pitch.py
powershell -ExecutionPolicy Bypass -File pitch/export_pdf.ps1
```

## Шрифты

Макет использует шрифты **Exo 2** (заголовки) и **Inter** (текст), они лежат в `frontend/public/fonts/`.
- Windows: правый клик по `.ttf` → «Установить»
- macOS: `cp frontend/public/fonts/*.ttf ~/Library/Fonts/`
