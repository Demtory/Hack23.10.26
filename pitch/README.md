# Питч-дека (защита проекта)

`risk-desk-pitch.pptx` — **9 слайдов**, 16:9. Это актуальная презентация для защиты:
она собрана вручную (Figma/PowerPoint), поэтому правки вносятся прямо в файл.

Рядом лежит `risk-desk-pitch.pdf` — та же дека для показа с любого устройства.

## Структура

1. **Титул:** Risk Desk, целевая аудитория, QR демо-стенда.
2. **Проблемы маркетолога:** время на разбор, приоритет, текст обращения.
3. **Дашборд:** сводные потери, градации риска, топ клиентов.
4. **Клиенты:** сортировка, фильтр срочности, экспорт когорты.
5. **Карточка клиента:** причины риска и готовый черновик письма.
6. **Настройки модели:** веса, бизнес-пресеты, No-Code конструктор факторов.
7. **Данные:** импорт снимка и симуляция демо-событий.
8. **Решение:** вектор обращения и черновик сообщения на примере.
9. **Финал:** результат и QR репозитория.

Заметки докладчика есть на слайдах **1, 2, 8, 9** — открывайте режим докладчика
в PowerPoint. Слайды 3–7 — экраны продукта, их показывают вживую с комментарием.

## QR-коды

- **Слайды 1–2** — QR входа на демо-стенд: ведёт на `/api/v1/auth/demo?token=…`
  и открывает панель **без пароля**.
- **Слайд 9** — QR репозитория: <https://github.com/Demtory/Hack23.10.26>.

Демо-QR связан с токеном `DEMO_LOGIN_TOKEN` на сервере. Если токен сменили —
перевыпустите картинку и замените её в презентации:

```bash
.venv/bin/python scripts/demo_qr.py --token "<новый токен>" --out pitch/qr-demo.png
```

Замена QR внутри `.pptx` (сохраняет позицию и размер):

```bash
python - <<'PY'
from pptx import Presentation
prs = Presentation("pitch/risk-desk-pitch.pptx")
blob = open("pitch/qr-demo.png", "rb").read()
for index in (1, 2):
    for shape in prs.slides[index - 1].shapes:
        if shape.name == "Picture 12":
            part = shape.part.related_part(shape._element.blipFill.blip.rEmbed)
            part._blob = blob
prs.save("pitch/risk-desk-pitch.pptx")
PY
```

Затем пересоберите PDF (LibreOffice или `pitch/export_pdf.ps1` на Windows).

## Про `build_pitch.py`

Старый генератор деки оставлен как исторический: он собирал прежнюю 7-слайдовую
версию и **не является источником актуальной презентации**. Его вывод теперь
пишется в `pitch/generated-deck.pptx` и не перезаписывает ручную деку.

## Шрифты

Макет использует **Exo 2** (заголовки) и **Inter** (текст), они лежат в
`frontend/public/fonts/`.

- Windows: правый клик по `.ttf` → «Установить»
- macOS: `cp frontend/public/fonts/*.ttf ~/Library/Fonts/`
