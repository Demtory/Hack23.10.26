# Питч-дека

`risk-desk-pitch.pptx` — 9 слайдов, 16:9, собирается скриптом `build_pitch.py`
(текст и раскладка в коде, не картинки). У каждого слайда есть заметки для
докладчика — откройте «Заметки» в PowerPoint.

## Что внутри

1. Титул: «Кому звонить сегодня — и что ему сказать»
2. Проблема: данные есть, приоритета нет
3. Решение: три вопроса кейса в одном экране
4. Модель: шесть признаков, веса, формула денег
5. Честность: почему не ML и почему это сильная сторона
6. Действие: письмо клиенту под ситуацию
7. Прогноз оттока: факт и прогноз разделены
8. Инженерия: одна команда, 422 теста, CI, SSO, 10 000 клиентов
9. Ограничения и следующий шаг

## Пересобрать

```bash
pip install python-pptx
python pitch/build_pitch.py
```

Скриншоты берутся из `docs/screenshots/`, поэтому сначала пересоберите их,
если интерфейс менялся (`npx playwright test capture-screens.spec.ts`).

## Шрифты

Макет использует Exo 2 и Inter — они лежат в `frontend/public/fonts/`.
Установите их на машине, где показываете деку, иначе PowerPoint подставит
системный шрифт: вёрстка не поедет, но фирменный вид потеряется.

```bash
# macOS
cp frontend/public/fonts/*.ttf ~/Library/Fonts/
# Windows: правый клик по .ttf → «Установить»
```
